# Changelog

## 0.1.0: pre-release, 2026-11-05

First version, still under test:

- 26 tweaks across 10 components, each with evidence, sources, risks and a danger level
- Exact-value undo, a crash-safe journal, and state read live from the system
- Read-only system check, and a Myths screen listing what augeo deliberately doesn't do
- Benchmarking with PresentMon: noise floor, per-tweak A/B tests and run history
- Timer tool and mouse polling meter
- A full-colour interface with hover, animation and command completion, which slows its drawing when it's behind another window or during a capture
